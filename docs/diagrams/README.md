# Diagram Sistem SolarScope

Diagram pada folder ini menggambarkan kebutuhan dan alur SolarScope pada tahap perancangan. File `.drawio` merupakan sumber yang dapat diedit melalui [diagrams.net](https://app.diagrams.net/), sedangkan file `.png` disediakan untuk pratinjau di GitHub.

## Use Case Diagram

- [Pratinjau](use-case/use-case.png)
- [Sumber yang dapat diedit](use-case/use-case.drawio)

Diagram menggunakan istilah umum **layanan data radiasi eksternal**. Pada implementasi, layanan tersebut adalah NASA POWER Climatology (`NasaPowerClient`).
